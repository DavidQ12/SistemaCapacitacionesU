Sistema web para el registro, seguimiento y análisis de las capacitaciones del personal docente y administrativo de una universidad.

Objetivo

Reemplazar los controles manuales en Excel mediante una plataforma centralizada que permita gestionar las capacitaciones y conservar el histórico acumulado por año.

Tecnologías

Python 3.12

Django

SQLite (desarrollo inicial)

Módulos previstos

Registro de personal docente y administrativo

Gestión de capacitaciones

Registro de participantes

Seguimiento y control de asistencia

Historial de capacitaciones por año

Reportes y estadísticas
